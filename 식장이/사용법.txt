==============================================================
 식장이(음식만들기) 자동 — 사용법
==============================================================
 이 폴더(식장이) 하나만 있으면 됨. 순서대로 1번부터 하면 끝.
 이미 깔아서 잘 쓰고 있으면 9번(실행)만 보면 됨.

--------------------------------------------------------------
 1. 파이썬 설치 (컴퓨터에 처음 한 번)
--------------------------------------------------------------
  - https://www.python.org/downloads/ 에서 다운로드
  - 설치 첫 화면에서 "Add python.exe to PATH" 꼭 체크 → Install Now
    (이걸 빼먹으면 py 명령어가 안 먹힘 → 지우고 다시 설치)

--------------------------------------------------------------
 2. 필요한 프로그램 설치 (컴퓨터에 처음 한 번)
--------------------------------------------------------------
  - 시작 메뉴에서 cmd 검색해서 열고 아래 한 줄 붙여넣기 → 엔터

      py -m pip install mss numpy pyautogui keyboard pillow pygetwindow truststore

  - 설치 중에 cmd 창 안을 클릭하면 멈춘 것처럼 보임 → 엔터 한 번 누르면 계속됨

--------------------------------------------------------------
 3. 파일 받기
--------------------------------------------------------------
  - 브라우저 주소창에 붙여넣기 → ZIP 이 받아짐

      https://github.com/pol112ii/joycity-food/archive/refs/heads/main.zip

  - 압축을 풀면 안에 "식장이" 폴더가 있음 → 그 폴더를 바탕화면에 꺼내두기
  - 앞으로 명령어는 전부 "식장이" 폴더에서 실행:
      식장이 폴더를 열고 → 위쪽 주소창을 클릭 → cmd 입력 → 엔터
      (그러면 그 폴더 위치에서 cmd 가 열림)

  ※ 주장이(가구만들기)와 폴더를 섞지 말 것. 각자 자기 폴더에서만 실행.

--------------------------------------------------------------
 4. 게임 준비
--------------------------------------------------------------
  - F2 로 직업 창을 열고 [직업활동] 을 눌러 제작 창을 띄워 둠
  - 창 위치는 아무 데나 둬도 됨 (봇이 창 제목으로 찾아감)

--------------------------------------------------------------
 5. 창 위치 재기 (한 번만)
--------------------------------------------------------------
      py measure_cook.py

  - 화면에 나오는 안내대로 그 지점에 마우스를 올리고 F1
      F1 = 기록 / F2 = 방금 찍은 것 다시 / ESC = 그만두기
  - 1~7번: 직업활동 버튼, 재료 슬롯 1·2번, 인벤토리 3칸, 시작 버튼
  - 8번이 되면: 재료를 넣고 [시작] 을 눌러서 식장이 창(온도계)을 띄운 뒤 계속
      8. 온도계(세로 유리관) 맨 위 끝
      9. 온도계 맨 아래 끝
     10. 식장이 창 안의 아무것도 없는 진초록 바탕 한 점
  - 끝나면 cook_layout.json 파일이 생김 (이게 창 위치 기록)
  - 마지막 "점검" 숫자 확인:
      인벤토리 간격  가로 / 세로 가 거의 같으면 정상 (예: 42.2 / 42.2)
      온도계 좌우 차이 가 0 에 가까우면 정상
      → 이상하면 다시 py measure_cook.py

  ★ 창 크기가 바뀌었으면 다시 py measure_cook.py → 바뀐 부분 번호만 골라서 다시 잼
      1. 직업활동 버튼   2. 제작 창   3. 식장이 창(온도계)   (그냥 엔터 = 전부)

  ★ 다른 컴퓨터에서 이미 잰 cook_layout.json 이 있으면, 그 파일을 이 폴더에
    복사해 넣고 5번은 건너뛰어도 됨 (화면 배율이 달라도 그대로 맞음)

--------------------------------------------------------------
 6. 재료 아이콘 등록
--------------------------------------------------------------
  - 제작 창을 띄우고, 재료 슬롯은 비어 있는 상태에서:

      py auto_cook.py 캡처

  - 폴더 안에 items 폴더가 생기고 cell_1_1.png 같은 사진들이 들어감
  - 탐색기 위쪽 [보기] → [표시] → [파일 확장명] 체크 (.png 가 보이게)
  - 빈 칸/필요 없는 사진은 삭제, 쓸 재료만 이름을 재료 이름으로 바꾸기
      예) cell_1_3.png → 노란꽃.png
  - 주의
      · cell_ 로 시작하는 파일은 봇이 무시함 (이름을 꼭 바꿔야 등록됨)
      · 노란꽃.png.png 처럼 .png 가 두 번 붙으면 안 됨
      · 같은 재료를 여러 장 넣으려면 끝에 숫자만: 노란꽃1.png, 노란꽃2.png
      · 다른 재료는 이름 자체를 다르게 (꽃1, 꽃2 는 같은 재료로 합쳐짐)

--------------------------------------------------------------
 7. 레시피 적기
--------------------------------------------------------------
  - auto_cook.py 를 마우스 오른쪽 → [메모장으로 열기] (또는 연결 프로그램 → 메모장)
  - Ctrl+F 로 RECIPE 를 찾아서 이렇게 적기:

      RECIPE = [
          ("파란꽃", 1),
          ("노란꽃", 2),
      ]

  - 주의
      · 이름은 items 폴더의 파일 이름과 글자 하나까지 똑같이 (띄어쓰기도)
      · 줄 앞에 # 이 붙어 있으면 메모로 취급돼서 무시됨 → # 은 지우기
      · 개수 합계는 슬롯 수(3) 이하
      · 같은 재료 2개면 인벤토리에 그 재료가 2칸 이상 있어야 함
        (한 칸에 몰려 있으면 '부족함' 으로 멈춤)
  - 저장 (Ctrl+S)

--------------------------------------------------------------
 8. 텔레그램 알림 (원하면)
--------------------------------------------------------------
  - auto_cook.py 를 메모장으로 열어서 아래 세 줄 채우기
      TELEGRAM_TOKEN   = "봇 토큰"
      TELEGRAM_CHAT_ID = "채팅 번호"
      NOTIFY_NAME      = "이 컴퓨터 이름"   (예: "규남본체", "정희노트북")
  - 토큰은 깃허브가 공개라서 비워둠 → 예전에 쓰던 auto_cook.py 에서 복사하거나
    텔레그램 @BotFather 대화에서 확인
  - 비워두면 알림 없이 그냥 동작함

--------------------------------------------------------------
 9. 실행
--------------------------------------------------------------
      py auto_cook.py

  - F8 = 시작 / 정지,  F9 = 완전 종료
  - 비상시: 마우스를 화면 왼쪽 위 구석으로 확 밀면 즉시 멈춤
  - 폰 텔레그램에 '현황' 이라고 보내면 화면 사진과 상태를 답장해줌
      (특정 컴퓨터만: '현황 규남' 처럼 이름 일부를 붙이기)
  - 순서: F2 직업 창 → 직업활동 → 재료 넣기 → 시작 → 온도 조절(, . 키)
          → 식장이 창이 닫히면 한 판 끝 → 재료가 떨어질 때까지 반복
  - cmd 창(봇)은 하나만 켜기. 여러 개 켜면 재료를 중복으로 넣음
  - 식장이 봇과 주장이 봇을 동시에 켜지 말 것 (같은 창을 써서 꼬임)

--------------------------------------------------------------
 10. 문제가 생기면
--------------------------------------------------------------
  - "재료가 부족함 ... 차이값: 0.0"
      → 재료 아이콘이 등록 안 된 것. 6번 파일 이름 확인 (.png.png / 철자 / cell_)
        cmd 에서 dir items 로 파일 이름 확인
  - 재료를 하나도 안 넣고 바로 시작함 / "RECIPE 가 비어 있음"
      → 7번 레시피 줄 앞에 # 이 붙어 있는지 확인
  - 재료를 엉뚱하게 넣음
      → cmd 창이 여러 개 켜져 있지 않은지 확인 (전부 닫고 하나만)
  - 온도가 계속 너무 높거나 낮게 머묾
      → 온도계를 잘못 잰 것. 5번 다시 (온도계 맨 위 / 맨 아래 끝을 정확히)
  - ", . 키를 눌러도 온도가 안 움직임"
      → auto_cook.py 에서 COOK_FOCUS_CLICK 에 식장이 창 안 빈 곳 좌표를 넣으면
        시작 직후 그 창을 한 번 클릭해서 활성화함 (measure.py 로 좌표 확인)
  - 창을 못 찾는다고 나옴
      → 그 창(직업/제작/식장이)이 실제로 떠 있는지 확인.
        떠 있는데도 못 찾으면 게임 업데이트로 창 제목이 바뀐 것 → 물어보기
  - 새 버전 받기
      → 3번처럼 ZIP 을 받아서 식장이 폴더의 auto_cook.py 만 바꿔 넣기
        (items 폴더, cook_layout.json 은 그대로 두기)
        새 auto_cook.py 에 7번 레시피, 8번 텔레그램을 다시 적어야 함
  - 그래도 안 되면 cmd 화면을 복사(또는 사진)해서 물어보기

  ※ 참고 파일 (보통은 안 써도 됨)
      scan_test.py      재료 인식 확인 (클릭 없이 인벤토리 칸별 인식 결과만 출력)
      measure.py        마우스 위치의 좌표/색 보기
      arrange_windows.py 창 배치 저장/복원 (이제 안 해도 됨)
      capture_items.py  예전 방식(좌표 고정) 아이콘 캡처 — 지금은 6번 명령으로 대신

--------------------------------------------------------------
 매크로 방지 확인 창 (자동)
--------------------------------------------------------------
  - 봇이 1초마다 조이톡 창을 보다가 '매크로 방지 확인' 창이 뜨면 바로 멈춤
  - 텔레그램으로 확인 창 사진 + 1초마다 알림 (30초 동안)
  - 사진 속 숫자 4자리를 텔레그램으로 답장하면 → 봇이 입력칸에 치고 [확인]을 누름
      (숫자는 사람이 읽어서 보내야 함 — 봇은 받은 숫자를 대신 쳐주기만 함)
      틀렸으면 '그대로예요' 알림과 새 사진이 옴 → 다시 숫자를 보내면 됨
      컴퓨터가 여러 대면  3042 규남  처럼 이름 일부를 붙이면 그 컴퓨터만 입력
      숫자가 아닌 답장(아무 글자)은 알림만 멈춤
  - PC 앞에 있으면 직접 입력하고 [확인] 눌러도 됨
  - 확인 창이 사라지면 몇 초 쉬고 하던 걸 이어서 함
  - 45초가 지나도 안 사라지면 멈춘 채로 둠 → 확인 후 F8
  - 확인 창이 떠 있을 때  py auto_cook.py 매크로검사  를 하면 잘 알아보는지 검사함
    (macro_test.png 저장 — 못 알아보면 이 그림을 보내주세요)
  - 확인 창을 알아봤을 때 그림은 macro_debug.png 로 저장됨
