==============================================================
 의장이(재봉틀) 자동 — 사용법
==============================================================
 이 폴더(의장이) 하나만 있으면 됨. 주장이/식장이 폴더와 섞지 말 것.
 주장이를 이미 쓰는 컴퓨터면 1번(설치)은 건너뛰어도 됨.

--------------------------------------------------------------
 1. 필요한 프로그램 (컴퓨터에 처음 한 번)
--------------------------------------------------------------
  - cmd 를 열고 아래 한 줄 붙여넣기 → 엔터

      py -m pip install mss numpy pyautogui keyboard pillow pygetwindow

--------------------------------------------------------------
 2. 폴더 열기
--------------------------------------------------------------
  - 의장이 폴더를 바탕화면 등에 두고
    폴더를 열고 → 위쪽 주소창 클릭 → cmd 입력 → 엔터
    (앞으로 명령어는 전부 이 cmd 창에서)

--------------------------------------------------------------
 3. 창 위치 재기 (한 번만 — F1 로 7군데)
--------------------------------------------------------------
  - 게임에서 F2 로 직업 창 → [직업활동] 으로 제작 창을 띄워 둠

      py measure_sew.py

  - 안내대로 그 지점에 마우스를 올리고 F1
      F1 = 기록 / F2 = 방금 것 다시 / ESC = 그만두기
      1. 직업 창 [직업활동] 버튼
      2~3. 제작 창 재료 슬롯 1번, 2번
      4~6. 인벤토리 첫 칸 / 첫 줄 맨 오른쪽 칸 / 5번째 줄 첫 칸
      7. 초록 [시작] 버튼
  - 끝나면 match_layout.json 이 생김
  - "인벤토리 간격 가로 / 세로" 가 거의 같으면 정상

  ※ 의장이 창(회색 천)은 안 재도 됨 — 봇이 화면에서 알아서 찾음
  ※ 게임 업데이트로 창이 바뀌면 다시 실행 → 바뀐 부분 번호만 골라서 다시 잴 수 있음
  ※ 주장이 폴더의 match_layout.json 을 복사해 오면 안 됨 (창 이름이 달라서)

--------------------------------------------------------------
 4. 재료 그림 등록 (한 번만)
--------------------------------------------------------------
  - 제작 창을 띄우고, 재료 슬롯은 비어 있는 상태에서:

      py auto_match.py 캡처

  - items 폴더에 cell_1_1.png 같은 사진들이 생김
  - 쓸 재료만 이름을 재료 이름으로 바꾸기 (나머지는 지워도 됨)
      예) cell_1_2.png → 실.png
      · cell_ 로 시작하는 파일은 무시됨 (이름을 꼭 바꿔야 등록됨)
      · 실.png.png 처럼 두 번 붙으면 안 됨 (탐색기 [보기]→[파일 확장명] 켜고 확인)
      · 같은 재료 여러 장은 끝에 숫자만: 실1.png, 실2.png

--------------------------------------------------------------
 5. 레시피 적기
--------------------------------------------------------------
  - auto_sew.py 를 오른쪽 클릭 → [메모장으로 열기]
  - 위쪽의 RECIPE 줄을 재료에 맞게 고치기 (이름은 items 그림 이름과 똑같이)

      RECIPE = [("실", 1), ("천조각", 1), ("단추", 1)]

      · 숫자는 넣을 개수, 합계 3 (재료 칸이 3칸)
      · 같은 재료 2개면 ("실", 2) 처럼
  - 저장 (Ctrl+S)

--------------------------------------------------------------
 6. 실행
--------------------------------------------------------------
      py auto_sew.py

  - F8 = 시작/정지,  F9 = 종료
  - 비상시: 마우스를 화면 왼쪽 위 구석으로 → 바로 멈춤
  - 제작 창이 닫혀 있어도 F2 → 직업활동 으로 알아서 엶
  - 재료 넣기 → 시작 → 박음질 → 반복 (쉬는 시간 없이 계속)
  - 게임 중에는 마우스/키보드를 건드리지 말 것

--------------------------------------------------------------
 7. 게임 중에 봇이 하는 일
--------------------------------------------------------------
  - 마우스로 바늘을 띠가 내려오는 칸으로 미리 옮겨 둠
  - 노란 띠 = < 키(왼박음), 파란 띠 = > 키(오른박음)
  - 띠가 빨간 실선에 닿는 순간 바로 뒤에 누르고, 띠가 끝나기 바로 전에 뗌
  - 키를 누르면 왼박음/오른박음 버튼이 청록색으로 바뀌는데, 그게 화면에 보일 때까지
    걸리는 시간(키 반응)을 봇이 직접 재서 그만큼 미리 누르고 뗌
    (그래서 첫 띠 하나만 조심스럽게 늦게 누르고 일찍 떼고, 그 다음부터 딱 맞춤)
  - 점수가 깎이면(빨간 실) 바로 떼고 스스로 맞춤 → cmd 에 [보정] 이라고 뜸
  - 맞춘 값은 sew_learn.json 에 저장돼서 다음에 켜도 이어서 씀
  - 한 판 끝나면 이렇게 나옴:
      (키 반응 0.05초 · 화면 한 바퀴 평균 9ms 최대 40ms · 박음질 줄 21 · ...)
      ★ 3판 끝 — 성공 (점수 250 · 52초 · 누름 15번 · 빨간 실 0번)

--------------------------------------------------------------
 8. 설정 (auto_sew.py 위쪽, 필요할 때만)
--------------------------------------------------------------
  RECIPE          재료
  MAX_GAMES       이만큼 하고 멈춤 (0 = 재료 떨어질 때까지)
  PRESS_AFTER     띠가 닿고 이만큼(초) 뒤에 누름  — 일찍 눌러 빨간 실이 나오면 올리기
  RELEASE_BEFORE  띠가 끝나기 이만큼(초) 전에 뗌 — 늦게 떼서 빨간 실이 나오면 올리기
  REST            False = 쉬지 않음 (기본) / True = 쉬는 시간 있음
  SHORT_EVERY     짧게 쉬는 간격 (판 수)
  SESSION_MINS    한 번에 하는 시간(분) → 끝나면 제작 창 닫고 자리 비움

--------------------------------------------------------------
 9. 문제가 생기면
--------------------------------------------------------------
  - 판을 시작할 때 이 폴더에 sew_debug.png 가 저장됨
    (봇이 천/띠 자리/박음질 줄/점수 막대를 어디로 읽었는지 그린 그림)
    → 이상하면 이 그림 + cmd 창 내용을 보내주세요
  - "천을 못 찾음" → py measure_sew.py 다시 실행 → 3번(의장이 창) 골라서 잼
  - 키를 눌러도 버튼이 안 바뀌면 봇이 의장이 창 제목줄을 눌러 다시 선택함
  - 빨간 실이 계속 나오면: cmd 창 내용 전체 + sew_debug.png 를 보내주세요
    (판마다 나오는 "(키 반응 … 화면 한 바퀴 …)" 줄이 원인 찾는 데 중요)
  - 맞춘 값을 처음부터 다시 하려면 sew_learn.json 을 지우면 됨
