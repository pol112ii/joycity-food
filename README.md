# 조이톡2 미니게임 자동

폴더 하나가 봇 하나야. 각 폴더 안의 `사용법.txt`를 1번부터 따라 하면 돼.

| 폴더 | 내용 | 실행 |
|---|---|---|
| `식장이/` | 음식만들기: 재료 넣기, 시작, 온도 조절(`,` `.` 키) | `py auto_cook.py` |
| `주장이/` | 가구만들기: 재료 넣기, 시작, 카드 짝맞추기 | `py auto_match.py` |
| `예전파일/` | 예전 버전 (지금은 안 씀) | |

받기: https://github.com/pol112ii/joycity-food/archive/refs/heads/main.zip

- 두 봇 모두 창을 제목으로 찾아서 동작해. `measure_cook.py` / `measure_match.py`로 한 번만 재면 되고, 창을 옮겨도 다시 잴 필요가 없어.
- 봇은 한 번에 하나만 켜야 해. 여러 개를 켜거나 식장이와 주장이를 동시에 켜면 서로 꼬여.
- 텔레그램 토큰은 저장소가 공개라서 비워 뒀어. 각 컴퓨터에서 직접 넣어야 해.
