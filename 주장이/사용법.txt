==============================================================
 주장이(가구만들기 / 그림 맞추기) 자동 — 사용법
==============================================================
 이 폴더(주장이) 하나만 있으면 됨. 순서대로 1번부터 하면 끝.
 이미 깔아서 잘 쓰고 있으면 10번(실행)만 보면 됨.

--------------------------------------------------------------
 1. 파이썬 설치 (컴퓨터에 처음 한 번)
--------------------------------------------------------------
  - https://www.python.org/downloads/ 에서 다운로드
  - 설치 첫 화면에서 "Add python.exe to PATH" 꼭 체크 → Install Now
    (이걸 빼먹으면 py 명령어가 안 먹힘 → 지우고 다시 설치)
  ※ 식장이를 이미 깔았으면 1, 2번은 건너뛰기

--------------------------------------------------------------
 2. 필요한 프로그램 설치 (컴퓨터에 처음 한 번)
--------------------------------------------------------------
  - 시작 메뉴에서 cmd 검색해서 열고 아래 한 줄 붙여넣기 → 엔터

      py -m pip install mss numpy pyautogui keyboard pillow pygetwindow truststore

  - 설치 중에 cmd 창 안을 클릭하면 멈춘 것처럼 보임 → 엔터 한 번 누르면 계속됨

--------------------------------------------------------------
 3. 파일 받기
--------------------------------------------------------------
  - 브라우저 주소창에 붙여넣기 → ZIP 이 받아짐

      https://github.com/pol112ii/joycity-food/archive/refs/heads/main.zip

  - 압축을 풀면 안에 "주장이" 폴더가 있음 → 그 폴더를 바탕화면에 꺼내두기
  - 앞으로 명령어는 전부 "주장이" 폴더에서 실행:
      주장이 폴더를 열고 → 위쪽 주소창을 클릭 → cmd 입력 → 엔터
      (그러면 그 폴더 위치에서 cmd 가 열림)

  ※ 식장이(음식만들기)와 폴더를 섞지 말 것. 각자 자기 폴더에서만 실행.

--------------------------------------------------------------
 4. 창 위치 재기 (한 번만)
--------------------------------------------------------------
  - 게임에서 F2 로 직업 창 → [직업활동] 으로 제작 창을 띄워 둠
    (창 위치는 아무 데나 — 봇이 창 제목으로 찾아감)

      py measure_match.py

  - 화면에 나오는 안내대로 그 지점에 마우스를 올리고 F1
      F1 = 기록 / F2 = 방금 찍은 것 다시 / ESC = 그만두기
  - 1~7번: 직업활동 버튼, 재료 슬롯 1·2번, 인벤토리 3칸, 시작 버튼
  - 8번이 되면: 재료를 넣고 [시작] 을 눌러서 카드판(주장이 창)을 띄운 뒤 계속
      8. 카드 왼쪽 위 (1행 1열)
      9. 카드 오른쪽 위 (1행 5열)
     10. 카드 왼쪽 아래 (5행 1열)
  - 끝나면 match_layout.json 파일이 생김 (이게 창 위치 기록)
  - 마지막 "점검" 숫자 확인:
      인벤토리 간격 가로 / 세로 가 거의 같으면 정상 (예: 42.2 / 42.2)
      카드 간격 가로 / 세로 가 거의 같으면 정상 (예: 72.0 / 72.0)
      → 이상하면 다시 py measure_match.py

  ★ 다른 컴퓨터에서 이미 잰 match_layout.json 이 있으면, 그 파일을 이 폴더에
    복사해 넣고 4번은 건너뛰어도 됨 (화면 배율이 달라도 그대로 맞음)

--------------------------------------------------------------
 5. 재료 아이콘 등록
--------------------------------------------------------------
  - 제작 창을 띄우고, 재료 슬롯은 비어 있는 상태에서:

      py auto_match.py 캡처

  - 폴더 안에 items 폴더가 생기고 cell_1_1.png 같은 사진들이 들어감
  - 탐색기 위쪽 [보기] → [표시] → [파일 확장명] 체크 (.png 가 보이게)
  - 빈 칸/필요 없는 사진은 삭제, 쓸 재료만 이름을 재료 이름으로 바꾸기
      예) cell_1_2.png → 석분.png
  - 주의
      · cell_ 로 시작하는 파일은 봇이 무시함 (이름을 꼭 바꿔야 등록됨)
      · 석분.png.png 처럼 .png 가 두 번 붙으면 안 됨
      · 같은 재료를 여러 장 넣으려면 끝에 숫자만: 석분1.png, 석분2.png
      · 다른 재료는 이름 자체를 다르게

--------------------------------------------------------------
 6. 레시피 적기
--------------------------------------------------------------
  - auto_match.py 를 마우스 오른쪽 → [메모장으로 열기] (또는 연결 프로그램 → 메모장)
  - Ctrl+F 로 RECIPE 를 찾아서 이렇게 적기:

      RECIPE = [
          ("석분", 2),
          ("하급키트", 1),
      ]

  - 주의
      · 파일에 처음 들어 있는 예시 줄은 앞에 # 이 붙어 있음
        # 이 붙어 있으면 메모로 취급돼서 무시됨 → # 은 꼭 지우기
      · 이름은 items 폴더의 파일 이름과 글자 하나까지 똑같이
      · 개수 합계는 슬롯 수(3) 이하
      · 한 칸에 여러 개 쌓여 있어도 됨 (같은 칸을 여러 번 우클릭함)
  - 저장 (Ctrl+S)

--------------------------------------------------------------
 7. 속도 (원하면)
--------------------------------------------------------------
  - auto_match.py 에서 MOUSE_SPEED 를 찾아 숫자만 바꾸기
      작을수록 빠름.  지금 0.4
      0.7 = 느긋하게 (한 판 약 46초)
  - 처음부터 끝까지 같은 속도로만 움직임 (판 후반에 빨라지는 기능은 꺼져 있음)

--------------------------------------------------------------
 8. 카드 인식 확인 (처음 한 번 권장)
--------------------------------------------------------------
      py match_test.py

  - 클릭은 안 하고 보기만 함. 카드판을 띄우면 자동으로 찾음
  - 카드를 직접 몇 장 뒤집어 보면서 화면 표시 확인:
      ?  = 뒷면,  O = 뒤집힌 카드,  X = 폭탄,  . = 판정 실패
  - 뒤집은 카드가 O, 폭탄이 X 로 나오면 정상. "." 이 나오면 화면을 보내서 물어보기
  - 끝내려면 Ctrl+C

--------------------------------------------------------------
 9. 한 판만 시험 (처음 한 번 권장)
--------------------------------------------------------------
  - 재료를 직접 슬롯에 넣고, 시작 버튼만 누르면 되는 상태로 만든 뒤:

      py match_once.py

  - F8 = 시작 (시작 버튼 클릭 → 짝맞추기 → 한 판 끝나면 자동 종료), F9 = 종료
  - 짝을 잘 맞추면 10번으로

--------------------------------------------------------------
 10. 실행
--------------------------------------------------------------
      py auto_match.py

  - F8 = 시작 / 정지,  F9 = 완전 종료
  - 비상시: 마우스를 화면 왼쪽 위 구석으로 확 밀면 즉시 멈춤
  - 순서: F2 직업 창 → 직업활동 → 재료 넣기 → 시작 → 카드 짝맞추기
          → 카드 창이 닫히면 한 판 끝 → 재료가 떨어질 때까지 반복
  - cmd 창(봇)은 하나만 켜기. 여러 개 켜면 재료를 중복으로 넣음
    (auto_match.py 와 match_once.py 도 동시에 켜지 말 것)
  - 식장이 봇과 동시에 켜지 말 것 (같은 창을 써서 꼬임)

  ■ 문제가 생기면
  - 재료를 하나도 안 넣고 바로 시작함 / "RECIPE 가 비어 있음"
      → 6번 레시피 줄 앞에 # 이 붙어 있는지 확인
  - 재료를 엉뚱하게 / 너무 많이 넣음
      → cmd 창이 여러 개 켜져 있지 않은지 확인 (전부 닫고 하나만)
  - "재료를 인벤토리에서 못 찾음"
      → 5번 파일 이름 확인 (.png.png / 철자 / cell_).  cmd 에서 dir items
  - 카드를 이상한 데 누름 / 카드판을 못 읽음
      → 4번 다시 (카드 3군데를 카드 정가운데에), 8번으로 확인
  - "비정상적 입력" 경고가 뜸
      → 7번 MOUSE_SPEED 를 올려서(느리게) 다시
  - 새 버전 받기
      → 3번처럼 ZIP 을 받아서 주장이 폴더의 auto_match.py 만 바꿔 넣기
        (items 폴더, match_layout.json 은 그대로 두기)
        새 auto_match.py 에 6번 레시피, 7번 속도를 다시 적어야 함
  - 그래도 안 되면 cmd 화면을 복사(또는 사진)해서 물어보기

  ※ 참고 파일 (보통은 안 써도 됨)
      input_test.py      '비정상적 입력' 원인 찾기용 진단 도구
      measure.py         마우스 위치의 좌표/색 보기
      arrange_windows.py 창 배치 저장/복원 (이제 안 해도 됨)
